**Tuần 5:** [Tích hợp Amazon SageMaker AI Triage (3 cấp độ) & Pre-consultation Report](1.5-week5/)

**Tuần 6:** [Hoàn thiện Doctor Portal (Giao diện Split View) & Patient Mobile Bottom Sheet Booking](1.6-week6/)

**Tuần 7:** [Giám sát hệ thống với AWS CloudWatch, Stress Test bài toán Race Condition đặt lịch](1.7-week7/)

**Tuần 8:** [Đóng gói Docker, Cấu hình CI/CD GitHub Actions lên AWS EC2, tổng kết và bàn giao](1.8-week8/)
